# IGL-voice-AI  
**Голосовой чат с ИИ для приватного общения**  

## Возможности  
- 🎤 Голосовой ввод (Whisper.cpp).  
- 🧠 Локальный ИИ (LLaMA 3 8B).  
- 🔊 Озвучка ответов (Piper TTS).  
- 🚀 Полная оффлайн-работа.  

## Установка  
```bash  
git clone https://github.com/yourname/IGL-voice-AI  
cd IGL-voice-AI  
npm install  
```
